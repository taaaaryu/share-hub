# サマスターの作業レポート

## 表現の基準（2026-10-29）

- 本編は画像中心。大きなスクリーンショットと、仕組みを解説するイラスト・図解を組み合わせる。
- 1つのまとまりは主張1つ、短い見出し、短いキャプションを基本にする。文字だけの長い章を連続させない。
- 詳しい背景・条件・確認事項は折りたたみか詳細版へ置く。意味や根拠を削るために短縮しない。
- 実画面と説明用の図は明示して分ける。未確認の指標・効果を図で確定結果に見せない。
- IBM風の白・黒・青、IBM Plex、スマホで拡大できる画像を基本にする。
- 公開許可のない映像・名前を含む画像はローカル完全版へ。公開用は安全なスクショと自作図で説明する。
