スマホの写真を、MacのUSBへ。

写真保存アプリ · 利用ガイドと検証結果 · 2026-10-22

写真・動画を複数選び、好きな名前のZIPにまとめて、Macに接続したUSBへ保存するローカルアプリです。実USBへの保存と内容照合まで確認しました。iPhone実機での接続確認はこれからです。

起動と使い方

アプリはMacで動かします。スマホの画面は写真を選んで送る役割です。インターネット上のサーバーへ写真を預ける必要はありません。MacにはPython 3.10以上が必要です。

  1. USBをMacにつなぎ、アプリフォルダの「写真をUSBへ.command」を開きます。開けないときは付属READMEの手動起動を使います。
  2. 検出されたUSBの名前・保存先・空き容量を確認し、番号を選びます。「保存する」と入力して書き込みを許可します。
  3. iPhoneから使うなら、Macと同じ信頼できるWi-Fiに接続し、「Wi-Fi」と入力します。MacだけならEnterです。
  4. Macに表示された接続URLを、iPhoneのSafariで開きます。「#token=」以降も含めたURL全体が必要です。127.0.0.1で始まるURLはMac専用です。
  5. 写真・動画を複数選び、ZIPの名前を入力し、保存先への同意にチェックを入れて保存します。送信後のZIP確認が終わり、「保存完了」と表示されるまで画面を開いておきます。
  6. 終了はMacのターミナルでControl+C。USBはFinderから安全に取り出します。

同じWi-Fiでも、ゲストネットワークでは端末間通信が禁止される場合があります。Macのスリープ、VPN、ファイアウォールも接続に影響します。アプリはルーターやファイアウォールの設定を自動で変えません。

Googleフォトは端末保存を経由

初版ではGoogleフォトの写真をいったんiPhoneにダウンロードし、アプリの写真選択から指定します。Googleフォトで写真や動画を選び、「その他」→「ダウンロード」を使います。すでにカメラロールにある場合はダウンロードが表示されないため、そのまま端末の写真を選びます。Google公式のiPhone向け手順

Google Photos Picker APIを使うとGoogleフォトから直接選択できますが、Google CloudのAPI設定とOAuth認証、選択セッションの管理が必要です。今回はGoogleアカウント設定なしで使える構成を優先しました。共有シートからこのWebアプリへ直接渡す機能は実装していません。Picker API公式ガイド

保存先とZIPを確認してから完了

起動時にmacOSのディスク情報から、外付けUSB・マウント先・書き込み可否を確認します。保存前と確定前にも同じ機器・ボリュームかを照合します。USBを外したときに、Mac内の似た名前のフォルダへ切り替えて保存しません。

アップロードしたデータはUSBの一時ZIPへ順に書き込みます。全ファイルの破損検査を通してから正式なZIP名に確定します。通常の通信中断や保存失敗では一時ZIPを削除します。同じ名前のZIPや写真には「(2)」などを付け、既存ファイルを残します。

項目仕様
件数・容量1回500件・合計2GiBまで
対応形式JPEG / PNG / HEIC / HEIF / WebP / GIF / TIFF / MOV / MP4
ファイル名UTF-8の日本語名。長すぎる名前・パス表記を拒否
空き容量送信サイズとZIPの余裕分を保存前に確認
認証起動ごとに発行する接続キーと接続元の制限

拡張子と先頭の形式識別情報を確認しますが、画像全体のデコードやマルウェア検査ではありません。ZIPは写真をまとめる箱で、JPEGや動画はもともと圧縮されているため大幅な容量削減は期待できません。選択後のファイルの画質は変えません。

実USBの確認はMac内から接続したブラウザで実施しました。スマホ幅での画面確認は、実際のiPhoneやWi-Fi通信の試験を置き換えるものではありません。Tailscale経由でも、スマホ幅のブラウザからHTTPSで合成PNGを送信し、Mac内の一時フォルダでZIP保存と内容一致を確認しました。既存の別サービスは維持しています。実USBへのHTTPS接続確認も成功しました。ログイン時の自動起動は設定していません。

外出先は本人の端末間だけ接続

同じWi-Fi版はHTTPのため、通信そのものは暗号化されません。信頼できる家庭内ネットワークで使い、接続キー付きURLを公開しないでください。

外出先はMacとiPhoneをTailscaleの同じ非公開ネットワークへ参加させ、本人の端末間だけ接続できるルールにする方式が候補です。接続先端末ではWebサーバーが動作している必要があります。Tailscale専用の起動用ファイルを追加しました。「Tailscaleで写真をUSBへ.command」を開き、USBを選んで許可すると、Tailscale内だけで開けるHTTPS URLが表示されます。iPhoneのTailscaleをオンにし、そのURL全体をSafariで開いて写真を選びます。通常は専用の8443番を使い、既存サービスを上書きしません。終了はControl+Cです。ルーターのポート転送や一般公開は行いません。Tailscaleの端末接続・非公開のServe機能

このMacではOS側の名前解決に問題があり、検証時は端末名とTailscale IPの対応をブラウザへ明示しました。HTTPS証明書の検証は有効です。iPhoneで「サーバが見つかりません」と表示される場合は、Tailscale接続とTailscale DNSの利用設定を確認してください。iPhone実機では未検証です。

突然の電源断・強制終了・USB取り外しでは一時ファイルの削除ができない場合があります。またSafariの写真選択でHEICがJPEGになる場合があり、Live Photosの組、アルバム、編集履歴の復元は保証しません。保存結果を確かめてから元写真を整理してください。
